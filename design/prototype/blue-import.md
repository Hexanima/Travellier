## Interaction contract

All data is fictitious, state is local and resets on reload. Voting replaces only the demo user's vote; no automatic confirmation. Participation never changes confirmation. Forms do not imply backend persistence. Unsupported creation, native calendar and composer show a clear notice. Trip dates remain transport-derived. Collage is a future-only prior extension.
