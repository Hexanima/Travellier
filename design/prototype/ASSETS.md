## Typography

public/assets/manrope.woff2: self-hosted Latin variable Manrope from Google Fonts. public/assets/manrope-LICENSE.txt preserves SIL OFL 1.1 and the Manrope Project Authors attribution. The active blue system uses this same font.

## Source vectors

public/assets/figma/: sixteen original SVGs downloaded unchanged for frames 7:5 and 9:5. Exact source URLs/metadata remain in review/figma-base/trips-context.json and itinerary-context.json. CSS masks recolor the original shapes; route/divider slots preserve the source 1.5px height. No source icon paths were redrawn.

Calendar, clock, up, down and close paths in public/exported-screens.mjs are reused verbatim from the original ../travellier-figma-helpers.js authoring script. Their inline SVG geometry is code-native; these are not newly sourced assets or a full-screen image reconstruction. Pre-existing inline glyphs in the studio/post/gallery remain prior prototype elements.
